DOCUMENTATION 6
API/Data Flow & Instagram + Cloudinary Integration
This document explains how the videography site will fetch, display, and update videos automatically from Instagram using a hashtag, and how Cloudinary can be used to store and serve videos added manually during development.
1. Instagram API Integration
Objective: Allow the client to add new videos to the portfolio herself without needing access to the site code.
How it works:
	1.	The site fetches posts from the client’s Instagram account using Instagram Graph API (requires an Instagram Business or Creator account).
	2.	Only posts containing the portfolio hashtag #anikeshotit are retrieved.
	3.	The API returns the following data for each post:
	•	Media URL → link to the video file or thumbnail
	•	Caption → contains hashtags and descriptions
	•	Media Type → video or image
	•	Timestamp → when the post was published
	4.	The Next.js app parses the caption for category hashtags, e.g.:
	•	#wedding → goes under Weddings
	•	#event → goes under Events
	•	#fashion → goes under Fashion
	•	#food → goes under Food
	•	#product → goes under Products
	•	#lifestyle → goes under Instagrammable / Lifestyle
	•	#videoediting → goes under Video Editing
	5.	Once categorized, the post is rendered in the correct VideoCarousel component on the portfolio page, with:
	•	Playable video embedded directly on the site
	•	Expand-on-click modal
	•	Horizontal carousel scrolling
	•	Hover effects
	•	Fully responsive design

Important Notes:
	•	She must include both #anikeshotit and the category hashtag in her IG post for it to show correctly.
	•	Posts missing the category hashtag can be placed in a “Miscellaneous” section or flagged for manual review.

2. Cloudinary Integration (for initial/development videos)
Objective: Allow developers to host larger video files for the initial site build without relying on Instagram.
How it works:
	1.	During development, videos provided by the client are uploaded to Cloudinary.
	2.	Each video is stored with metadata:
	•	URL
	•	Caption / Description
	•	Category
	3.	Videos are fetched from Cloudinary by the Next.js site and displayed using the same VideoCarousel components.

Benefits:
	•	Avoids large video file size limitations on Vercel
	•	Supports high-quality video playback
	•	Ensures all front-end effects (carousel, hover, expand) work consistently.
3. Data Flow Overview
Step-by-Step:
	1.	Initial Site Build:
	•	Videos provided by client uploaded to Cloudinary → added to portfolio categories manually.
	•	All frontend effects (carousel, modal, responsiveness) applied.
	2.	Post-Deployment Updates via Instagram:
	•	Site fetches Instagram posts with #anikeshotit hashtag via API.
	•	Caption parsed for category hashtags.
	•	Videos automatically rendered in the correct category on portfolio page.
	•	Same frontend effects are applied automatically (playable, expandable, carousel).
	3.	Rendering & Display:
	•	VideoCarousel receives an array of video objects from either Cloudinary or Instagram API.
	•	Each object includes:
	•	url → video file
	•	thumbnail → optional poster image
	•	caption → description
	•	category → section placement
	•	Carousel renders videos in proper order with swipe functionality.

4. Key Advantages of This Setup
	•	Self-Updating Portfolio: Client can add videos herself by posting on Instagram with proper hashtags.
	•	Consistent UI/UX: All videos (manual or IG-sourced) share the same layout, carousel, hover, and expand functionality.
	•	Free Hosting Friendly: Instagram-hosted videos reduce the need for heavy storage on Vercel.
	•	Scalable: New categories or videos can be added without coding.
	•	Client-Friendly: Minimal technical knowledge required; just post on IG.
5. Recommendations / Best Practices
	1.	Always include portfolio hashtag #anikeshotit on every IG post for portfolio inclusion.
	2.	Always include category hashtag for correct placement.
	3.	Keep Instagram videos short to ensure fast loading on the site.
	4.	Optional: Use Cloudinary for large/high-quality videos if needed during development or special projects.
